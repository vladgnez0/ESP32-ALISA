# ESP32-ALISA

Автономный голосовой ассистент на базе ESP32 с локальной нейросетью на Python-сервере: распознавание речи (Vosk), генерация ответов (GPT на transformers) и синтез речи (Piper TTS) — всё работает офлайн.

## Как это работает

```
   ┌───────────── ESP32 ─────────────┐              ┌──────────── Python-сервер ────────────┐
   │                                 │              │                                        │
   │  Касание TTP223 → запись 5 сек  │   UDP:54321  │  Vosk STT — распознавание речи (ru)    │
   │  Микрофон INMP441 (I2S, 16кГц) ─┼─────────────►│  GPT (transformers) — генерация ответа │
   │                                 │              │  Piper TTS — синтез речи → temp.wav    │
   │  Динамик MAX98357A (I2S)       ◄┼──────────────┼─ TCP:12345 — стрим PCM 16кГц mono      │
   │  OLED SSD1306 — «глазки»        │              │  FastAPI (порт 7000) — HTTP API        │
   └─────────────────────────────────┘              └────────────────────────────────────────┘
```

1. Пользователь касается сенсора — ESP32 записывает 5 секунд звука с микрофона и стримит его по UDP на сервер.
2. Сервер распознаёт речь моделью **Vosk** (русский язык).
3. Распознанный текст отправляется в локальную **GPT-модель** (диалоговая, с историей контекста).
4. Ответ озвучивается офлайн-движком **Piper TTS** (голос `ru-irinia-medium`).
5. Сервер поднимает одноразовый TCP-сервер и стримит готовое аудио (RAW PCM 16 кГц mono 16-бит) на ESP32.
6. ESP32 воспроизводит ответ через I2S-динамик. Всё это время OLED-дисплей показывает анимированные «глазки», отражающие состояние устройства.

## Аппаратная часть

| Компонент | Модель | Подключение |
|-----------|--------|-------------|
| Микроконтроллер | ESP32 DevKit | — |
| Микрофон | INMP441 (I2S) | WS=15, SCK=14, SD=32 (I2S_NUM_0) |
| Динамик/усилитель | MAX98357A (I2S) | WS=26, SCK=27, SD=25 (I2S_NUM_1) |
| OLED-дисплей | SSD1306 128×64 (SPI) | CS=5, DC=16, RST=17, SCK=18, MOSI=23 |
| Сенсорная кнопка | TTP223 | GPIO 4 |

### Состояния OLED-дисплея

| Состояние | Отображение |
|-----------|-------------|
| Boot | Обычные глаза с морганием |
| WiFi connecting | Глаза «бегают» по сторонам |
| Idle | Спокойные глаза с морганием |
| Recording | «Злые» глаза с бровями |
| Playing | «Радостные» глаза с улыбкой |
| Error | Крестики вместо глаз + текст ошибки |

## Серверная часть

### Требования

- Python 3.10+
- FFmpeg (в `PATH`)
- Опционально: CUDA-совместимый GPU (ускоряет GPT; проверка — `cuda_test.py`)

### Зависимости Python

```bash
pip install fastapi uvicorn vosk transformers torch pydub aiofiles flask requests
```

### Модели (скачиваются отдельно, работают офлайн)

| Модель | Путь | Назначение |
|--------|------|------------|
| [Vosk small ru](https://alphacephei.com/vosk/models) | `model/vosk-model-small-ru-0.22` | Распознавание речи |
| GPT (диалоговая, ru) | `model/gptmedium` | Генерация ответов |
| [Piper](https://github.com/rhasspy/piper) + голос `ru-irinia-medium.onnx` | `piper/`, `piper/models/` | Синтез речи |

### Запуск

```bash
python service.py
```

Сервис поднимает:
- **FastAPI** на `0.0.0.0:7000` — `GET /` (статус), `POST /gpt/` (текстовый запрос к GPT), `GET /stream` (HTTP-стрим MP3);
- **UDP-приёмник** на порту `54321` — голос с ESP32;
- **одноразовый TCP-сервер** на порту `12345` — отдача синтезированного ответа (закрывается через 7 с, если клиент не подключился).

### Веб-интерфейс (опционально)

Flask-чат с GPT с настройкой параметров генерации (top_k, top_p, temperature и др.):

```bash
cd web
python app.py
```

## Прошивка ESP32

Проект собирается в [PlatformIO](https://platformio.org/):

```bash
cd esp32-code
pio run --target upload      # порт задан в platformio.ini (COM24)
pio device monitor           # монитор на 115200 бод
```

Перед прошивкой в `src/main.cpp` укажите свои параметры:

```cpp
const char* ssid     = "Arduino";        // SSID WiFi-сети
const char* password = "12345678";       // пароль
const char* serverIP = "192.168.137.1";  // IP компьютера с service.py
```

## Шифрование

В проекте есть модули для защиты канала связи:

- `esp32-code/include/chicher.cpp` — полная реализация блочного шифра **«Магма»** (ГОСТ Р 34.12-2015): 64-битный блок, 256-битный ключ, 32 раунда;
- `secret.py` — Python-класс `MagmaCipher` (упрощённый XOR-вариант) с генерацией 256-битного ключа;
- `key_socket.py` — TCP-сервер для передачи сгенерированного ключа клиенту.

## Возможные доработки

- Активация по ключевому слову («кубик») вместо сенсорной кнопки — задел уже есть в `potok.py`
- Полноценное шифрование аудиопотока Магмой с обеих сторон
- VAD (детекция конца речи) вместо фиксированных 5 секунд записи
